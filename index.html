B×C×H×W → B×(CHW) → B×C×H×W

Accelerators move tensors as flat streams. This page shows how every element of an NCHW tensor gets a column address k in a B×(CHW) matrix, how the address is reversed, and the results: 11 tensor configurations, every round trip exact. No reshape, view, flatten or ravel is used.

① Flatten · indexing
k = c·H·W + h·W + w
② Reconstruct · inverse
c = k // (HW)  ·  r = k % (HW)
h = r // W  ·  w = r % W

04 · Performance

Cost grows linearly with tensor size

Each element costs one address calculation and one copy, so run time is O(B·C·H·W). The loop version (the submitted algorithm) costs about the same per element at every size. The vectorized cross-check uses the same formulas on whole index arrays and runs about 50–100× faster.

05 · Algorithm

The submitted code

From src/tensor_flat.py. Both functions use only loops, integer arithmetic and single-element indexing.

flatten_loop · B×C×H×W → B×(CHW)
def flatten_loop(I):
    B, C, H, W = I.shape
    flat = full((B, C*H*W), nan)
    for b in range(B):
        for c in range(C):
            for h in range(H):
                for w in range(W):
                    k = c*H*W + h*W + w
                    flat[b, k] = I[b, c, h, w]
    return flat
reconstruct_loop · B×(CHW) → B×C×H×W
def reconstruct_loop(flat, C, H, W):
    B, CHW = flat.shape
    HW = H * W
    I_hat = full((B, C, H, W), nan)
    for b in range(B):
        for k in range(CHW):
            c = k // HW
            r = k %  HW   # offset inside channel c
            h = r // W
            w = r %  W
            I_hat[b, c, h, w] = flat[b, k]
    return I_hat

Why it's lossless

k → (c,h,w) is a bijection. Because w < W and h < H, the terms c·HW, h·W and w never overlap, just as digits in a mixed-radix number don't. Every element is copied, never computed, so floats come back bit-for-bit identical.

Why the reference check matters

A round trip can come back exact even when the mapping is wrong, for example if both functions swap H and W the same way. Comparing the flattened tensor with np.reshape, which is kept in a separate labeled file, rules that out. The 3×5×7×11 case is there to catch exactly that kind of mix-up.

Why accelerators care

A systolic array is fed one row of B×(CHW) at a time. The address generator in hardware evaluates b·CHW + c·HW + h·W + w with counters and adders. That is the same arithmetic this page animates.
